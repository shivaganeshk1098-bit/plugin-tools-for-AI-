A Claude Code plugin that helps anyone get real value from AI for everyday work —
writing better prompts, taming long documents, drafting messages, cleaning up
meeting notes, understanding hard topics, translating, and polishing writing.

---

## 🧑‍💻 Agents

| Agent | What it does |
|-------|--------------|
| **prompt-engineer** | Turns a vague request into a clear, structured prompt — and teaches you why. |
| **researcher** | Researches a question and returns an organized, honestly-sourced answer. |
| **editor** | Polishes writing for clarity, tone, and correctness without losing your voice. |

## 🛠️ Skills

| Skill | Use it to… |
|-------|-----------|
| **write-prompt** | Turn a rough idea into a strong prompt (or fix one that's underperforming). |
| **summarize** | Get an accurate TL;DR and key points from long text. |
| **draft-email** | Draft or reply to an email in the right tone. |
| **meeting-notes** | Turn messy notes into a summary with decisions and action items. |
| **explain-simply** | Get any concept explained in plain language. |
| **translate** | Translate text naturally, preserving tone and meaning. |
| **improve-writing** | Polish any writing for clarity, grammar, and concision. |

## Installing

This plugin ships in the **plugin-tools-for-ai** marketplace:

```text
/plugin marketplace add shivaganeshk1098-bit/plugin-tools-for-AI-
/plugin install ai-enablement-kit@plugin-tools-for-ai
```

## Using it

Invoke a skill directly, or just ask in plain language:

```text
/write-prompt a prompt that turns bullet points into a polished LinkedIn post
/summarize <paste a long article>
/draft-email decline a meeting politely and propose next week
/meeting-notes <paste raw notes>
/explain-simply what is a vector database
/translate "Good morning, welcome!" into Telugu
/improve-writing <paste your paragraph>
```

Or delegate to an agent: *"Use the prompt-engineer to improve this prompt,"*
*"Have the editor polish my cover letter,"* *"Ask the researcher to compare X and Y."*
